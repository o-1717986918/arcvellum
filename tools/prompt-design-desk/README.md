# 场景主创提示词评审台

打开 scene-prompt-design-desk.html 即可离线使用。左侧有 20 个 v2 位和 6 个旧顶层复审位。

1. 选择提示词位，在“对照原稿”切换查看内置初稿与关联旧稿的完整文字。
2. 右侧是可修改的当前填写稿。“通过当前填写”确认这份文字。
3. 认可旧稿时，点“采用此旧稿并通过”。需组合多个旧位时展开“组合关联旧稿”，按列表顺序勾选并通过。可撤销上次采用。
4. 修改已通过的正文会取消通过；备注修改不影响正文决定。
5. 一键导出 JSON 或复制结构化文本，发回整理。导出含正文、备注、来源版本／摘要和通过时的原文。

已有浏览器填写稿保留；旧版“可整理”标记不自动等同于本次人审通过。可导入旧 v1 或新 v2 导出；未包含的提示词位保留，导入后可撤销。更换设备前导出备份；浏览器存储不可用／已满时页面提示改用导出。

来源是项目注册的内置提示词快照，未自动合并全局或作品级自定义覆盖。自定义稿可导入或粘贴。全部来源按文本显示，不执行其中的 HTML。采用旧稿保持原文；装载时仍须满足 v2 的权限和结构合同，冲突文案会再整理。

通过记录只存在浏览器与导出文件中。本页面不改项目档案、人格或运行开关。20 位 v2 均为文学初稿，尚未经过用户评审和真实模型场景对照；默认运行开关保持关闭。角色卡模板的 16 个占位符应各保留一次。

页面已做 DOM 操作与来源保真验证。浏览器工具策略曾拒绝打开本地页面，桌面／手机截图、实际渲染的重叠与横向溢出验收尚未完成。

## 构建与验证

在项目根目录、配置好 Python 的 src 路径后运行：

~~~powershell
$env:PYTHONPATH = (Join-Path (Get-Location) 'src')
python tools/prompt-design-desk/build_snapshot.py --output <输出目录>
node tools/prompt-design-desk/test_desk.cjs <输出目录>/scene-prompt-design-desk.html
~~~

源码分为元数据、状态与评审、文件导入导出、HTML 和样式。构建只读 Engine public.prompting；自包含产物无需网络或本地服务。

## 页面方向

沿用原页面的水青纸张和蓝黑墨色：纸面 #fbfdfd、底色 #eaf0f1、墨色 #18303b、青色 #087e78、批注色 #b8563e。宋体标题、雅黑正文、Consolas 来源编号。主元素是“来源全文｜可修改稿”的双页对照；窄屏按先来源后填写排列。目录序号对应实际提示词位顺序，颜色区分待评审与已通过，减少无关装饰。

~~~text
目录              来源全文                 当前填写稿
20 v2 + 6 顶层    内置初稿 / 关联旧稿        编辑 / 通过 / 撤销
                  来源版本与摘要             备注与通过状态
                  单份采用 / 组合采用
                  一键导出整套评审决定
~~~
