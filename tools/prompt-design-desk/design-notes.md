# 本轮提示词设计说明

共 20 位 v2 完整初稿：角色系统卡和主创填卡任务沿用已有设计，另外 18 位本轮首次写成；另展示 6 位现有顶层提示词待复审。初稿完成不代表文学验收完成。

## 1. 先对齐权限与真实交付

creator.protocol、material.shared.protocol、material.output.protocol、review.protocol 对齐当前 parser 和工具。主创独写正文与 SceneDelta；五类无档案检索或正式写入权。首轮必用类别自由选择，但系统校验真实调用。角色只看当次挂载，known 与 reference 分区；历史候选不能自动成为经历。

## 2. 作品人格与开场连续性

project_agent.creator_persona.v2 把用户意图变成持续的注意力、人物观和叙述气质，要求具体写作选择。只有明确记录的用户创作意图改变才更新版本。creator.identity 与 bootstrap 保留全篇意图、上场正文与 Delta、承诺、读者问题、文风和 Canon；开场投影或缺项需要补读，避免把短摘录当成完整来源。

## 3. 主创自己的创作循环

create、revise、delegation、archive、sandbox、selection 形成“读依据—形成意图—自己写委托—逐次选档案—读候选—取舍重写—交付与返修”。不要求凑齐五类、固定技法或固定笔记目录。保留构思被人物回应改变的空间，同时将选择与事实分开。

主创填角色卡继续强调鲜明甚至极度风格化：声线、注意力、联想、身体节奏和关系反应贯穿人物主轴。风格设计不能补造身份历史或扩大角色知识。

## 4. 四类描写与叙述的文学分工

| 模板 | 文学工作 | 事实边界 |
|---|---|---|
| environment | 从感知中心选择有关系的细节，让环境形成时间和注意力 | 不替人物行动，不新增关键环境事实 |
| character-description | 将人物特色写成可观察的形态和既有举止 | 不代说台词，不把内心猜测当成事实 |
| event-narration | 把场外信息组织成有先后、有处境和代价的阅读过程 | confirmed／attributed／proposed 分开 |
| scene-description | 让既有言行在空间中可理解，形成距离和感知路径 | 不为构图新增调度动作 |

模板要求完整文学候选，默认一条；确有不同文学处理时提供至多三条替代写法。主创仍负责叙述距离、心理、句法、衔接及整场结构。

## 5. 审读按作品意图判断

review 看真实阅读效果、人物差异、细节与节奏、视角与信息控制、连续性与 Delta。日常、亲近、滑稽、沉默和辨认均可成立。修订意见定位文本、说明影响和修复方向；不把“更文学化”当成意见，也不将私人审美升格为门禁。

审读任务没有档案或候选全文读取工具，提示词明确限制证据范围。缺项可要求主创补查，不能假称看过来源。文学通过不覆盖确定性失败或正式 Gate。

## 评审与后续

前端可以直接通过可用旧稿；原文与来源全部保存。旧独立 performance.plan 仅作参考，不恢复其角色委托创作权。固定协议也展示全文供评审，但装载需继续满足 v2 合同。

下一步按用户评审结果整理装载，再以冲突、日常、空间调度、设定揭示四类场景做新旧对照。检查人声、细节、信息控制、连续性、角色知识保密和素材可改写性。在完成文案与场景验收前保持默认未激活。
