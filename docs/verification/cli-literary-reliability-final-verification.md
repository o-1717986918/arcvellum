## Packaging Repair

The PyInstaller sidecar previously used console=False. On Windows that removed the streams Uvicorn relies on during initialization, so the process exited before the desktop shell could receive its ready-file. The package now retains the console subsystem; Tauri's shell runner launches sidecars with CREATE_NO_WINDOW, so this preserves a terminal-free user experience. tests/test_sidecar_spec.py prevents accidental reintroduction.
