# 星仪 W1 自动化视觉退出评审

> 日期：2026-07-27
> 范围：只读叙事投影、空间星仪、焦点、关系、阅读联动与视觉回归。

## 结论

W1 已达到产品退出条件。星仪不再处于“功能继续扩展”阶段，后续工作只接受缺陷修复、
性能回归和与自适应编排正式合同有关的增量投影。

## 自动化证据

- `npm run client:test`：41 files、128 tests passed。
- Playwright 100/300 场：五主题与四焦点组合通过。
- Playwright 检查：真实关系、章节主脊、章节目录、关系透镜、Canvas 像素、控件避让。
- SSE 检查：增量投影保留焦点与多开窗口身份。
- reduced-motion：核心探索能力等价。
- 千节点布局：六种空间语法均保持有限坐标和可寻址性，基线约 32–61 ms。

## 规模策略

全书与人物远景允许聚合为章节锚点、人物和当前任务；章节与场景焦点保留全书场景语义。
验收不会把“每个语义层都同时绘制千个 DOM 标签”误当作完整性。千场详细模式通过
节点计数、关系、Canvas 和交互门禁；整页 PNG 仅作为有受控 Chromium 环境时的非阻断
证据。

## 后续边界

- 不在 `OrreryWorkbench.vue` 继续堆叠算法或业务状态。
- 不建立第二套计划、Canon 或 Agent 运行事实。
- W6-9 只把正式 Creative Execution Plan、任务节点与重规划事件投影到现有 v3/SSE。
- 任何新布局提示继续通过只读、限幅、碰撞检查后的 `LayoutHintProvider`。
