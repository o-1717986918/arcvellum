# ArcVellum v0.99.6 发布验证

验证日期：2026-09-15

## 核心行为

- Project Agent 启动长期创作目标后，同一轮对话会绑定对应 Autopilot run。
- 后台执行期间只在进度发生变化时发送状态事件，不持续占用 Pi 推理进程。
- 目标完成、暂停、阻断或失败后，Project Agent 自动恢复同一会话，核验项目证据并向用户报告。
- 用户停止前端观察不会终止后台作品任务。
