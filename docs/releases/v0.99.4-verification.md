## 真实 Provider 证据

真实 Pi Worker 请求已经抵达用户配置的 DeepSeek Provider 与 `deepseek-v4-pro` 模型，Runtime、Provider 和模型路由均可确认。Provider 返回：

```text
402 Insufficient Balance
```

系统将其归类为 `provider-billing-required` 并安全暂停。该结果证明真实连接和错误分流可用；它不被记录为“真实模型完整文学闭环成功”。发布可复验的完整闭环证据来自确定性 Runtime/API/投影测试，外部账户恢复余额后可用同一路线补充真实文学生成证据。
