# ArcVellum v0.99.9

此维护版本修正了当前作品打开叙事星仪时可能出现的“暂时无法读取叙事场域 / Failed to fetch”，并调整创作中的数字判断与人物对白指导。

## 修复与调整

- 修复正式连续性条目或身份冲突进入星仪只读投影时的路径错误。带这些资料的作品现在可以通过认证的叙事投影接口读取。
- “一个又一个”等虚指反复不再被当作精确计数；当场问答、谈判、身份或债务辨认、选择、因果和连续性确实需要的数值可以保留。无关的陈设件数、动作次数和装饰性读数仍应在生成阶段改写。
- 规划、当前场景创作、旧场景生成入口及新默认文风统一使用上述语义口径。既有作品挂载的不可变文风版本未被改写。
- 生成提示要求从人物现有身份、欲望和关系压力中区分用词、句子形状、礼貌与回避方式；审读仅在持续混同损害人物或关系时要求返修。
- 禁词与基础中文标点仍由审查约束；未新增数字密度门禁或字数硬门禁。

## 验证边界

自动回归、生产构建与发布资产检查见 [发布验证记录](v0.99.9-verification.md)。本版本没有自动改写用户保存的创作质量配置。人物声线的真实模型 A/B 质量评估仍待完成，不能把提示词合同测试当作文学效果证明。

Windows 用户可运行 `ArcVellum_0.99.9_x64-setup.exe` 覆盖升级；作品资料保留在原用户数据目录。macOS 附件仍为未签名预览包，尚未经过 Developer ID 签名和 Apple notarization。
