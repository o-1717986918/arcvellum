# ArcVellum v0.99.2

ArcVellum v0.99.2 是一次围绕“可继续创作、可看懂状态、可完成交付”的稳定性更新。它收束了此前端到端创作测试发现的状态写回、任务资料和提示词边界问题，也补齐了默认文风、只读演示作品与交付入口。

## 本次更新

### 创作链路更稳

- 统一场景状态写回的候选来源、语义审查和连续性账本身份，减少旧项目在 `state-apply` 前反复重发任务的情况。
- 收紧任务包的资料清单、精确修订源和沙箱输出合同，模型只看到当前任务真正允许读取和写入的内容。
- 优化场景分支、编剧态、状态演化与连续性任务的提示词，保留文学判断所需证据，同时移除重复的宿主说明和流程噪声。
- 改进旧项目任务、乱码路径和历史角色身份的兼容读取，让已有作品能够沿当前状态机继续推进。

### 文风与演示作品

- 新增长篇创作默认文风预设：强调清楚、朴素、流畅的中文叙事，并通过现有文风挂载机制进入正式生成链路。
- 建立授权来源、阅读单元和只读演示包合同；安装后可从作品页安装《我胆小如鼠》星仪演示项目。
- 演示正文保留来源身份，不伪装为 Agent 生成、审查或晋升的原创产物。
- 阅读投影保留授权阅读单元声明的场景、章节和覆盖关系，星仪标题使用正式场景标题。

### 前端体验

- 作品页增加演示项目安装、安装状态和只读说明。
- 交付中心入口迁入星仪常驻工具坞：作品未满足交付条件时仍可查看缺失项，满足条件后同一入口会亮起。
- 修复交付入口被顾问浮窗遮挡的问题；真正的导出动作仍由正式交付门禁保护。
- Agent 观测与连续创作面板使用更完整的任务状态说明，减少只显示截断任务名的情况。

## 安装与升级

- Windows 10/11 x64 用户可运行 `ArcVellum_0.99.2_x64-setup.exe` 覆盖升级。
- 作品默认保存在用户文档目录，升级不会删除已有作品。
- 应用内更新使用与安装包同源的 Tauri updater 签名。

## 兼容性

- 项目格式、正式 CLI 状态机、任务包和既有作品目录保持兼容。
- 演示项目以只读母本安装；开始修改时应建立可编辑副本。
- Canon、人物状态、正文晋升和正式发布仍受原有 Gate、版本与审计约束。

完整构建、测试与安装包哈希见 [v0.99.2 发布验证记录](v0.99.2-verification.md)。
