# ArcVellum v0.95.2

## Dual-Workspace Review Reliability

- Rebuilt the Agent execution boundary around two workspaces: a complete control workspace for formal CLI commands and deterministic validation, plus a curated Agent workspace that contains only the task package's permitted reading set and writable outputs.
- Agent-authored artifacts are synchronized from the curated workspace to the control workspace only after output validation. This eliminates the previous contradiction where a task package advertised source paths that the Agent sandbox could not read.
- Scene review now records the exact candidate path as a system-owned fact. Revision tasks therefore retain an unambiguous reviewed source.

## Review Gate Repair

- `style_notes` is now evidence, not an automatic revision trigger. It can record why a below-threshold style choice is acceptable without reopening an otherwise passing candidate.
- Low-risk warnings must explicitly declare `blocks_pass: false`, use a narrow below-threshold/waiver resolution, or carry a clear non-blocking rationale. Any unclassified warning remains a hard review gate.
- The full-auto acceptance project was observed through independent review and formal promotion: the first scene became a promoted draft without bypass flags or manual file fabrication.
- Continuity-ledger author and review tasks now receive a field-level contract, and the Studio sandbox applies the same ledger checks as the core route before any writeback.
