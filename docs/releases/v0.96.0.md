# ArcVellum v0.96.0

ArcVellum v0.96.0 是一个可日常使用的阶段性版本。它不以削减文学门禁换速度，而是同时
收口叙事星仪、自适应编排基础和 Agent 任务吞吐。

## 叙事星仪 W1

- 章节、场景、人物和关系使用统一语义焦点，章节目录不再用首场景冒充整章。
- 增加关系透镜、人物焦点历史、搜索、小地图、离屏信标、方向键导航和正文双向定位。
- 增加套索比较、语义路径回放、节奏/张力/承诺/审查热力层和按作品隔离的书签。
- 100/300 场景的五主题、四焦点视觉矩阵通过；千场布局完成算法、Canvas 和交互规模门禁。

## 受审计的自适应编排基础

- Creative Execution Plan 已具备 schema、规范化、Lint、编译、模拟和持久化合同。
- Planner 与 Reviewer 使用隔离角色、独立会话和精确上下文账本。
- Mutation Receipt、Plan Event 与 Capability Broker 建立了计划、能力和写回的审计边界。
- 自适应计划当前只在 Shadow 模式运行，不能替代固定正式路线，也不能删除强制 Gate。

## 创作吞吐

- Agent 首轮直接获得许可资料的完整、带摘要快照，减少反复读取与被拒绝后的模型续轮。
- 确定性任务只建立最小 Agent 沙箱；带 CLI 前置命令的任务只在受保护产物生成后物化一次。
- 真实依赖集的确定性 staging 从约 0.371 秒降至约 0.092 秒。
- OpenCode 累计 usage 快照按稳定消息身份计算增量，吞吐面板不再重复累计 token。

## 验证

- Python：632 tests passed，1 skipped。
- Vue：41 files、128 tests passed。
- Architecture Audit：0 新增文件债务、0 新增函数债务、0 import cycle。
- Prompt Registry、Python compileall、Vue typecheck、生产前端构建与 sidecar provenance 均纳入发布门禁。

- AO-6：Execution Bundle、Context Cache、真正的同角色 session lease、资源锁和有限只读并发。
- AO-7：Progress Contract、checkpoint、恢复阶梯、受限重规划与无人值守 Campaign。
