# ArcVellum v0.97.2

ArcVellum v0.97.2 是一次针对 Agent 沙箱权限与确定性预检链路的稳定性修复。它不放宽任何正式创作 Gate，而是确保任务声明的能力与运行时实际提供的工具一致。

## Agent Runtime 修复

- 修复 `main-review-agent` 被无条件映射到只读 OpenCode reviewer 的问题。需要写入正式审查、规划或语义产物的任务现在使用可写 worker 沙箱。
- 保留纯编排 reviewer 与 planner 的只读隔离，不因修复文件写入任务而扩大无产物任务的权限。
- 运行角色选择改为能力契约驱动：`write-expected-outputs` 与正式 Agent 产物必须一致，矛盾契约会在执行前失败。
- 兼容 `composition-review` 等具名语义产物，不依赖单一 `agent-authored` 类型判断文件所有权。

## 解决的用户问题

- 修复模型已经在运行日志中生成完整内容，却因无法创建 `expected_outputs` 而反复出现 `sandbox output still fails deterministic preflight` 的问题。
- 长篇字数预算、故事架构、场景编剧审查等需要正式文件的审查任务获得与任务契约一致的写入能力。
- 失败运行不会被伪装成成功；确定性预检、写回范围与正式晋升门禁保持不变。

## 验证范围

- 使用真实长篇规划任务包验证 `main-review-agent -> worker` 的能力投影。
- 扫描受影响项目全部正式任务，检查角色、能力与产物所有权组合。
- Python 全量测试：929 项通过，1 项按预期跳过。
- Vue、TypeScript、冻结 Python sidecar、Tauri Windows 安装包、更新签名与版本同步由正式发布脚本复验。
