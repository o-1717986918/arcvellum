# ArcVellum v0.99.0

ArcVellum v0.99.0 的重点不是再堆一层功能，而是证明这套文学工程系统能够把一部真实作品从创作方向稳定推进到正式交付，并让持续扩展的代码库仍然保持清楚的模块边界。

## 两章三万字真实闭环

本版本通过与产品前端相同的公开 Studio API 创建干净项目，使用内置 Pi Worker、用户配置的真实模型连接和 `full_auto` 路径完成了一部两章、六场的正式作品。

- 六个场景均完成角色推演、分支决策、编剧态、正文生成、独立 AgentReview、必要修订、正式晋升、人物状态、Canon 与连续性写回；
- 两章正式 Markdown 合计 30080 个中文内容字符，达到三万字验收目标；
- `scene-development`、`longform-planning`、`review-and-audit`、`export-and-release` 四条正式路线分别检查 252、14、8、21 项 Gate，最终均为零阻断、零警告、零待办；
- 整书 Markdown、DOCX、版式报告和检查报告全部生成，摘要与发布清单一致；
- 交付正文不包含场景编号、工作流痕迹或内部项目标记，DOCX 检查警告为零。

这不是由测试脚本拼出的几段样稿，而是同一作品在正式状态机中持续完成规划、创作、审查、写回、章节发布和整书发布的产品路径证据。

## 模块化与面向接口开发

- 应用层、Runtime、文学内核、持久化、事件与 Vue 功能模块均建立了公开接口或端口；
- 新增模块目录、依赖边界、组合根和面向接口 Agent 开发标准，后续修改应先定位责任模块，再通过接口完成；
- Studio 内部不再直接导入 Engine 实现层，模块图与 OpenAPI/TypeScript DTO 可由工具生成并校验；
- Repair Context、Task Lifecycle、Scene Blueprint、Inventory 与 Workflow Contract 的高热度职责得到拆分，没有新增第二套状态机或重复 DTO；
- Architecture Audit 保持零新增违规、零循环依赖和零禁用依赖，不通过放宽基线掩盖复杂度。

## 可靠性与故障恢复

- Prompt 超限、修订超时、模型无活动、预检失败和工作流缺证据现在具有稳定错误代码、中文影响说明与可执行恢复动作；
- Pi Worker 的多产物写入、响应级工具租约、读取后提交纪律、精确修订来源和确定性预检均经过真实项目修复验证；
- 历史任务具备显式 `superseded` 终态，不再因为遗留 sidecar 制造虚假待办；
- Longform 审计输入不再被发布审批日志反向污染；历史晋升稿与当前晋升稿使用同一正式就绪语义；
- 整书发布对缺失、不可解析或非零阻断字段一律失败关闭。

## Prompt 与创作质量合同

- 模型只接收当前任务真正允许读取的证据，不再把宿主 Skill 说明、CLI 生命周期和无关项目地图重复塞入上下文；
- 正文、审查、修订、状态、Canon 和连续性任务保持独立角色与独立产物合同；
- 字数预算、场景功能、节奏、衔接、文风、读者问题和正式事实继续作为正文生成与晋升的硬约束；
- 修复回合只携带失败目标、相关摘录和仍有效的合同，不重放整份原始 Prompt；
- 机器事实由 Studio 规范化，模型不再负责手抄 ID、路径、摘要、schema 或会话身份。

## 验证

- Python：1274 项通过，1 项环境条件跳过；
- Vue：60 个测试文件、186 项断言通过，无未处理异步错误；
- Pi Worker：8 个测试文件、75 项通过；
- Prompt Registry：57 个 Prompt Asset、72 个任务 Prompt ID，校验通过；
- OpenAPI 合同、生成 TypeScript DTO、模块图、版本同步、Python 编译与 Vue 生产构建通过；
- Architecture Audit：16 项既有文件债务、110 项既有函数债务、0 个新增违规、0 个循环、0 个 Studio 内部 Engine 实现导入。

桌面安装包、Updater 签名、SHA-256 与生产侧车冒烟数据在发布构建完成后记录到 GitHub Release。

## 已知边界

- ArcVellum 仍处于 Beta。两章三万字证明了完整产品路径，但不能代替更多题材、更多供应商、弱网、长时间无人值守和 Windows 干净机矩阵验证；
- 模型凭证和推理费用由用户选择的服务管理，安装包不包含任何真实密钥；
- Pi Worker 继续以有界任务会话运行，尚未启用跨任务长期 Provider 会话或不受控子 Agent；
- v0.99.0 优先保证正式事实、审计与恢复可靠，不承诺所有模型在相同预算下获得相同文学质量。
