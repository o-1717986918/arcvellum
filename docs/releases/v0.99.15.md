# ArcVellum v0.99.15

本版降低创作链路的重复上下文开销，修正会话预算判断，并补齐桌面星仪的渲染兼容性。

- 长自然文本的整理请求使用原始分段 ID 的行首标记，避免把分段开头、结尾再复制进一份索引。历史大请求的序列化体积从 221,877 字节降至 130,318 字节，减少 41.3%；这是传输体积对照，不等同于计费 token 的降幅。原文保存、摘要绑定、精确引用与旧记录恢复继续保留。
- 私有会话复用优先依据模型上报的 token 计数，对新增内容使用保守上界，并计算系统提示、工具和输出预留。避免直接把中文 UTF-8 字节数当作模型 token 数；权限变更、资料撤回和未完成会话仍按原有规则隔离。
- 顶层 Agent 新增轻量运行状态视图，可直接获得状态、停因、下一步和完整资料入口。完整档案、正文、决策、诊断与控制工具仍可按需读取，摘要不代替文学判断与正式 Gate。
- 修复完整 JSON 交付语法错误时技术返修未携带反馈、导致缓存复用同一错误结果的问题。返修现在明确指出技术错误并形成不同请求；仍保留有界重试、失败记录和原文引用校验。
- 修复桌面安全策略下 Pixi 初始化失败导致星仪退回平面备用显示的问题，使用官方静态兼容模块，保持现有安全策略。

本版沿用现有模型连接、文学创作权限和更新签名身份。Windows 提供签名安装程序与更新清单；macOS 提供 Apple Silicon、Intel 未签名预览包。
