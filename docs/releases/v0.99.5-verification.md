## 任务协议与 Runtime

- 新任务使用 `arcvellum/task/v2`，Studio 通过结构化 Engine Operation 驱动七条正式 Route；v1 读取与已登记历史 schema 迁移仍有回归覆盖。
- OpenCode 已从普通产品 Runtime、API、设置界面和桌面安装资源中退出；通用 Runtime SPI 与外部适配入口保留。
- Pi Worker 连接探针使用单轮、无工具、无作品写权限的 conversation 模式。探针无需伪造正式任务上下文，可以直接验证用户选择的 Provider 与模型。
