# ArcVellum v0.99.7

v0.99.7 将作品对话放在桌面工作区中心，并调整叙事星仪与创作现场的呈现。文学内核、Pi Worker 和既有作品格式保持兼容。

## 面向创作者

- 新建对话时选择作品，对话随后归属该作品；从对话工作区进入星仪、正文、档案和创作现场。
- 对话右侧直接呈现当前作品及 Agent 工作状态，减少在多个页面间查找进度。
- 星仪采用更明亮的空间背景，保留章节、场景及作品关系的平移、缩放与节点查看。
- 创作现场区分候选内容与正式正文，便于观察正在进行的写作和审查。
- README 更新了来自当前界面的真实截图。

## 工程与兼容

- 为会话归属、页面入口、星仪显示和创作现场补充前端及浏览器级回归测试。
- Windows 安装包继续包含本地服务、文学内核、Pi Worker 与只读演示项目；无需单独安装 OpenCode。
- 同一标签工作流构建 Windows 更新包与 macOS Apple Silicon、Intel 未签名预览包。macOS 预览包未经过 Apple notarization。

## 升级说明

Windows 用户可运行 `ArcVellum_0.99.7_x64-setup.exe` 覆盖升级。作品和模型配置保存在用户数据目录，不由安装器清除。升级后可从对话工作区继续打开既有作品。
