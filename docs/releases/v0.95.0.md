# ArcVellum v0.95.0

## 正式文学工作流可靠性

- 将长篇规划、场景开发、正文候选、审查、晋升、状态演化与连续性账本收束为可追溯的任务契约；缺少前置证据时，正式路线不能跳步。
- 任务包明确限定可读取资料、预期产物、提交凭证与完成条件，平台 Agent 或内置 Worker 的写入会先经过隔离工作区、Schema、Lint 与路径审计。
- 修复形式化产物状态别名、候选稿显式输出、连续性账本材料校验等边界问题，并补充端到端测试，确保首个场景可从规划推进到正式正文晋升，再自然衔接下一场。

## 文学工程与可观测性

- 强化字数预算、节奏规划、读者问题、承诺兑现与场景衔接在场景任务和审查中的传递。
- 叙事星仪、阅读器、任务面板和运行事件继续使用真实项目资料；已完成正文可在创作推进时持续阅读。
- 应用与工程内核完成模块化边界整理，降低后续扩展 Agent Runtime、创作规则和桌面界面的耦合成本。

## 桌面交付

- Windows 安装包内置本地服务、文学工程内核和 OpenCode Runner，无需用户预装 Python、Node.js、Rust 或浏览器。
- 发布构建会校验 Python、Node、Cargo 和 Tauri 版本一致性，冻结并校验 sidecar 来源，生成签名安装包、更新签名和 `latest.json`。

## 验证

- Python 单元测试、源码编译、Prompt Registry、版本一致性、Vue 测试与生产构建均已进入发布门禁。
- 本版本的具体安装包、校验文件和自动更新清单随 GitHub Release 一并提供。
