# ArcVellum v0.97.3

ArcVellum v0.97.3 是一次以真实最小文学项目端到端闭环为验收依据的运行时稳定性更新。它不减少任何正式 Gate，而是修复任务能够生成内容、却可能在上下文、预检或状态写回阶段失去一致性的根因。

## 文学工程闭环验证

- 完成一个场景从上下文包、角色推演、分支选择、编剧构成、正文生成到独立 AgentReview 的完整链路。
- 正文通过字数预算、Style Lint、新角色资产审查、正式晋升和静态复核。
- 人物状态补丁经语义审查与摘要绑定审批后写回。
- 读者问题与承诺账本经独立 Reviewer 审查后应用，并由状态机自动进入下一场景。
- 实测场景的 40 个专属门禁全部通过，没有使用 debug waiver 或跳审参数。

## 运行时与数据修复

- 强制上下文层级现在是 Agent 授权资料集的权威组成部分，不会再被压缩后的 `agent_source_paths` 或大型可选文件挤出。
- 缺失、冲突或无法容纳的强制上下文会在 Agent 执行前明确失败，避免模型反复读取无权限资料后留下空产物。
- 人物状态写回改用 Round-trip YAML 解析；关系定义保持结构化记录，叙事关系变化进入独立状态字段。
- 自动迁移旧版本误写进 `relationships` 的字符串事件，并保持重复应用幂等。
- OpenCode 子进程使用 Studio 自有 HOME/Profile，避免用户目录中的无关配置污染内置 Runner。
- Runner 探针在输出文件未生成时保留原始超时或失败信息，不再由二次文件读取异常覆盖根因。

## 验证范围

- Python 全量测试：935 项通过，1 项按预期跳过。
- 架构预算审计通过：新增逻辑未扩大既有函数复杂度基线，也未引入反向依赖。
- 上下文预算、沙箱、OpenCode、状态写回和连续性账本均有针对性回归覆盖。
- Vue、TypeScript、冻结 Python sidecar、Tauri Windows 安装包、更新签名与版本同步由正式发布脚本复验。
