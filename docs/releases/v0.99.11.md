# ArcVellum v0.99.11

这一版把角色与环境的独立推演接入正式场景创作，并改进主创的素材交接、修订与现场可见性。

## 创作链路

- 角色按场景维持各自的扮演会话；主创可逐轮引入新的情势与信息，在单人、双人或多人场景中选择下一位回应者。环境 Agent 独立提供空间候选，主创负责正文、心理、设定展开及世界状态变化。
- 作品级角色标签可由顶层 Agent 查看和修改。新场景角色会话优先使用这些已保存的个性、声音、情绪和文学风格标签；未配置时仍由场景主创创作初始化标签。
- 主创收到按轮次排列的言行、情势变化与环境候选；完整推演仍保存在事务中供审查追溯。来源摘录为上一场结尾、最新方向、角色和世界资料留出位置，避免长文件按顺序挤占全部上下文。
- 主创提示把全书中的情节位移、人物情绪、叙事声音和段落节奏放在工程输出格式之前；修订提示鼓励主创重组正文，而不只逐项填补检查意见。既有事实、引用和审查合同保持不变。
- 修复 `lean-v2` 未实际加载项目最高优先级文风提示的问题。通用《弹性叙事》保留稳定的旧 ID，改写了易被误读为压缩情绪段落的两处措辞；旧挂载版本仍不可变。

## 使用与交付

- 创作现场展示角色推演的逐轮消息和历史记录，并改进正文修订痕迹的观察位置。
- 顶层 Agent 可在授权范围内管理作品档案与文风挂载、检查每场之后的宏观创作方向；作品未写完时也可导出当前 DOCX。
- 审查阶段增加短句堆叠提示，同时保留禁词、标点及既有文学规则；本版没有增加新的创作阻断门槛。

《文学少女》本地作品已补齐五名已建档角色的持久扮演标签，作为作品数据保存在用户作品目录，不随安装包分发。回归验证能证明素材与标签到达相应 Agent；文风改善仍需以真实模型成稿和读者评价检验。详见[验证记录](v0.99.11-verification.md)。
