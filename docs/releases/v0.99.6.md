# ArcVellum v0.99.6

ArcVellum v0.99.6 完成了 Lean v2 文学内核、作品库级 Project Agent 与桌面工作区的首轮产品收敛。用户可以用一条自然语言要求创建、推进并交付作品；后台创作结束后，同一轮对话会自动核验结果并回复。

## 面向创作者

- Project Agent 可以管理整个作品库，创建作品、记录方向、设置质量与节奏、挂载文风、处理项目决定并启动长期创作目标。
- 长期目标运行时，对话保持可观察状态，显示当前创作阶段和已完成任务数；完成或阻断后自动恢复对话，无需再次追问。
- Agent 等待后台创作时会释放 Pi 推理进程，避免为“等待”消耗模型连接与额度。
- 新桌面主页以 Project Agent 和叙事星仪为双主界面；正文、创作现场、档案、IDE、文风与设置作为统一工作区中的查看面。
- 空作品库继续随安装包提供只读《我胆小如鼠》演示项目。

## Lean v2 文学内核

- 场景创作由精简事务完成生成、语义审查、修订与提交，以精确正文哈希和场景增量作为正式证据。
- Lean 场景提交已接入长篇审计、章节工作区、整书审查和最终发布；旧 strict-v1 义务不会误报到 Lean v2 项目。
- `pass_with_notes` 与 `approve_with_notes` 使用共享清洁语义；派生章节工作区不再反向使长篇审计过期。
- 缺失章节导出时，发布流程会回到现有导出路线补齐产物，避免形成新的平行任务链。

## Project Agent 长任务闭环

- `project_goal_manage` 返回最小、非敏感的运行绑定回执。
- Project Agent Job 在 Autopilot 执行期间保持活跃，通过 SSE 仅发送有意义的进度变化。
- 目标完成、暂停、阻断或失败后自动启动收尾推理；它会先读取项目证据，必要时诊断并恢复，随后给出最终回答。
- 停止对话观察不会暗中终止后台作品任务，用户仍可稍后重新进入项目查看状态。

## 工程与兼容

- Pi Worker 继续作为普通桌面安装的唯一内置正式 Agent Runtime，OpenCode 不再是产品依赖。
- Task v2、结构化 Engine Operation、双工作区、确定性预检和事务写回保持兼容。
- 项目审查、长篇规划、人物身份、历史场景晋升和结构化输出的兼容边界得到统一修正。
- Windows 安装器、签名更新包、macOS Apple Silicon 与 Intel 预览包继续由同一标签工作流构建。

## 升级说明

Windows 用户可以直接运行 `ArcVellum_0.99.6_x64-setup.exe` 覆盖升级。作品、模型凭证、项目目录和阅读进度不会被安装程序删除。首次安装或作品库为空时，应用会自动提供随包演示项目。
