# ArcVellum v0.99.12

这一版让场景主创按文学意图调取素材，开放分层提示词编辑，并完成一轮有兼容边界的全仓清理。

## 创作内核

- 主创以开放文字记录本场希望产生的阅读效果，以及可选的读者已知、误知和留白安排。它可以直接写作，也可以说明用途后向角色、环境、人物、事物或场面描写器按需取材；候选仍由主创选择和成稿，不直接成为 Canon。
- 角色保留作品级人格化初始化与场景内续演。描写器使用有界初始化和当前场景历史；导演的 `cue` 与 `director_note` 进入成稿交接。场景主创保留意图、素材取舍和未决问题的有界摘要，重启后可继续。
- 软字数不足交场景审读判断，不再触发旧自动补段。跨场景只用正式提交的正文、语义增量和连续性交接作为已确认依据。

## 提示词与项目 Agent

- **设置 → 提示词工作台**列出协议、身份、阶段、作品表达及动态资料等层，标明用途和覆盖来源。文学指引可按作品或全局保存版本、预览组装、激活历史或撤销覆盖；协议和事实权限只读。正式任务继续使用既有 PromptProgram 编译路线。
- 项目 Agent 可只准备 `lean-v2` 规划并停在推演前，也可补齐规划内缺失档案。长工具回执、恢复检查点、计划摘要诊断和结构化档案字段修改与真实服务状态对齐。

## 安全清理

逐项检查 37 项候选后，移除了断开的前端页面与样式、旧场景补长和预先全套角色推演、无调用的私有包装及旧直连 Provider 孤岛。v1 Schema 的发布镜像与 Engine 规范源对齐并有测试防漂移。公开别名、旧 HTTP 和受 `1.0.0` 移除窗口保护的读取路径继续保留。[逐项结果](https://github.com/o-1717986918/arcvellum/blob/main/docs/architecture/reviews/full-repository-cleanup-execution-2026-09-28.md)

这一版仍是 Beta。程序回归验证了权限、状态与交接合同；人物辨识、留白和节奏的实际改善仍需真实模型成稿与盲评。Windows 安装版 GUI/升级实测及 macOS 签名公证也属于独立验收。详见[验证记录](https://github.com/o-1717986918/arcvellum/blob/main/docs/releases/v0.99.12-verification.md)。
