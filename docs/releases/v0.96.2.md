# ArcVellum v0.96.2

ArcVellum v0.96.2 是一版面向大项目稳定性、受控创作策略和后续运行效率的增量更新。
它没有提前启用尚未完成的自适应生产路线，而是先把场景策略契约、计划修订边界和顾问
大项目读取行为做扎实。

## 本次更新

- 场景创作策略现在可以用机器可校验的字段表达 RP 深度、分支数量、叙事距离、目标汉字
  数、修订策略与回退等级。
- 场景 Plan Patch 会校验计划身份、版本、项目指纹、作用域、允许操作和 Freedom Budget；
  失败修改不会激活，也不会改变历史计划。
- `simulate-scene` 支持 `light`、`targeted`、`full` 三种推演深度。精简推演只缩小资料
  范围，不取消人物行动、世界后果、分支压力、Canon 风险或写回候选。
- 顾问面对大型项目时优先读取稳定创作资产，并过滤可重建的运行痕迹，避免快照文件数量
  超限。
- 顾问仍保留完整项目索引，可按需定位未进入首轮快照的正式资料。
- 候选成果通过预检后，界面会以清晰中文提示用户查看写回差异，不再显示内部英文状态。
- 任务在受控修复和后续写回成功后会清除旧预检错误，不再让已恢复的流程继续显示为阻断。

## Token 与吞吐路线

本版本把 Token 优化加入 v1 正式工程路线，但没有把规划误报为已完成能力。下一批将先
建立按任务类型分配的上下文预算、唯一模型执行信封、Token 分类归因和增量修复，再逐步
进入内容缓存、有界会话复用和 Execution Bundle。

任何吞吐优化都不得跳过 RP、分支、正文独立审查、promotion、state/canon/continuity
写回或发布 Gate。
