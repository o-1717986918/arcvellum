# ArcVellum v0.99.3

ArcVellum v0.99.3 把叙事星仪、内置 Agent Runtime 与跨平台交付链收束到同一条可验证路线。它不是单纯放大节点的一次视觉修补：星仪现在采用参考原型等效的章节布局与场景簇算法，桌面端则正式以项目内置 Pi Worker 为默认文学执行器。

## 面向创作者

- 叙事星仪采用更有层次的章节主脉、黄金角场景簇与类型化关系节点，真实项目中的长标题、密集场景和多类关系仍保持可读。
- 高频仪器窗统一为紧凑磨砂窗口，拖动前后尺寸与滚动行为一致，正文、推进、规则和 Agent 观测不会再被无意义空白挤压。
- 连接与模型页面以 Pi Worker 为唯一主配置入口；每个创作角色的模型选择可以持久保存，不再自动回到 OpenCode Zen 默认模型。
- 顾问与代理用户通过内置 Pi Worker 的无工具会话工作，继续保持流式回答和明确的项目权限边界。

## Runtime 与安装包

- Pi Worker 覆盖主创、审查、规划、顾问、代理用户、文风学习与作品反推的正式入口。
- Windows 安装包内置 Pi Worker 及固定 Node 运行时，不再捆绑 OpenCode 二进制，也不要求用户预装其他 Agent 平台。
- OpenCode 仍保留为可显式启用的外部兼容适配器，方便已有环境迁移。
- 新增 macOS Apple Silicon 与 Intel 构建路线。当前 DMG 带 `unsigned-preview` 标识，用于工程预览；正式公共分发仍需 Apple Developer ID 签名与 notarization。

## 工程质量

- Pi Worker 资源下载按平台校验官方 SHA-256，并生成可复验安装回执。
- Windows、macOS arm64、macOS x64 分别装配与其架构匹配的 Node 和 Python sidecar。
- GitHub Actions 在发布前重跑 Vue、Python、Pi Worker、Prompt Registry、架构审计、资源来源验证和桌面构建。
- 角色对话、模型目录与模型选择经过职责拆分，未以新增兼容分支换取架构债务。

## 升级说明

Windows 用户可以直接运行 `ArcVellum_0.99.3_x64-setup.exe` 覆盖升级。原有作品、模型凭证与项目目录不会被安装程序删除；升级后请在 **设置 -> 连接与模型** 中确认各角色使用的 Pi Worker 模型。
