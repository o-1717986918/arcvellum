# ArcVellum v0.97.4

ArcVellum v0.97.4 introduces an experimental Pi-based literary Worker and tightens the Studio boundary around model output. It also makes the narrative Orrery more usable under real project density. Pi remains opt-in in this release; the stable Runtime and every formal literary Gate remain available and unchanged.

## Experimental Pi literary Worker

- Added a narrow Worker built on the Pi Agent core for ArcVellum task packages rather than general-purpose coding work.
- Added task-specific execution profiles, explicit reasoning ceilings, supported-state authorization, and structured prompt v3 canaries.
- When the final turn already contains valid outputs, the Worker now completes through local terminal validation instead of reporting a false turn-budget failure.
- Studio runs its authoritative deterministic preflight after Pi completes. Exact, repairable issues may receive one short fresh-process repair in the same isolated workspace.
- Repeated identical failures stop immediately through a digest-based no-progress guard.

## Real creation evidence

The same Pi Worker prototype and real model connection completed reproducible task-package slices for:

- long-form planning: 38.22 seconds;
- roleplay simulation: 56.84 seconds;
- formal prose candidate generation: 90.03 seconds;
- independent candidate review: 74.87 seconds.

The model-facing matrix is complemented by deterministic promotion tests covering Style Lint, exact-candidate review, provenance, and formal promotion. These measurements demonstrate technical value, not a claim that Pi is already the default zero-configuration Runtime.

## Narrative Orrery and workspace

- Persisted instrument windows now reflow when the viewport changes instead of clipping outside the stage.
- Dense desktop layouts use compact collision-aware placement; narrow layouts preserve one active instrument and collapse the rest.
- Added a visible workspace tidy command for recovering a clean instrument layout.
- Removed duplicate evidence, promise, review, and character relationship painting between Pixi and SVG layers.
- Dense projects retain all relationship data while lowering non-focused glow and animation pressure.
- Improved compact instrument typography and internal scrolling without turning the Orrery into a card-heavy dashboard.
- Concurrent application-shell and overview requests now share one workspace snapshot calculation, preventing a 1,000-scene project from stalling during repeated initialization.

## Known boundaries

- Pi is experimental and must not silently replace the stable Runtime.
- Prompt v2 prose and roleplay contexts remain heavier than the target architecture; future work should compile approved Creative Context Capsules and use task-capability routing.
- A single 7B or 14B local model is not considered a quality-equivalent replacement for planning, prose, style, and independent review. A measured hybrid route is recommended.
