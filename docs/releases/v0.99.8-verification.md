# ArcVellum v0.99.8 发布验证

验证日期：2026-09-22。

## 缺陷来源与修正范围

本版本以《潮痕之下》五章、35 场、92,348 个正式正文字符的顶层 Agent 端到端运行为主要缺陷来源。该运行已经完成规划、逐场创作、返修、提交和全书导出，但暴露了相邻场景重复、身份称谓碰撞、连续性未写回、章节检查点重复、正文与流程进度混淆、重复章号以及文风证据范围表述过大等问题。完整事实记录见 `docs/quality/top-agent-100k-five-chapter-e2e-2026-09-22.md`。

修正没有新增数字密度 Gate，也没有把章节目标字数改成发布硬等式。确定性标点规范和违禁表达仍为阻断项；句群节奏、人物声音、事件唯一性和数字必要性由规划、生成和语义审读负责。

## 本地自动验证

- Python：1479 项测试完成，除 1 项因 Windows 符号链接环境条件跳过外，其余全部通过。
- Vue：75 个测试文件、245 项测试通过。
- Pi Worker：10 个测试文件、102 项测试通过。
- 提示词注册表：59 个资产、73 个任务标识通过；17 个确定性提示词评估用例通过。在线模型语义评估未运行。
- TypeScript 检查与生产前端构建通过，共生成并同步 145 个前端资产。
- Rust/Tauri：`cargo check --locked` 通过。
- 架构审计、模块地图、版本同步、Python 编译与 CLI `doctor`/`--help` 通过。
- 两章真实路线集成测试确认：每章仅一个带 `chapter_id` 的检查点、正文实绩快照存在、章号不重复、全书 Markdown 与 DOCX 均可生成。
- 连续性定向测试确认：正式 SceneDelta 原子投影到连续性、Canon 候选和时间线；同一身份引用被赋予两个角色描述时产生显式冲突记录。

## 人工与端到端边界

修复后完成了确定性全量测试、两章真实路线集成测试和生产前端构建。发布前的五章长篇运行是本轮缺陷证据，不冒充修复后的文学复验；本地验证也没有把文风预设盲评表述为整部成稿盲评。

本机未完成干净 Windows 10/11 虚拟机的首次安装、覆盖升级、应用内更新和卸载实机验收。正式安装包、updater 签名、`latest.json`、校验和以及 macOS 预览包由 `v0.99.8` 标签工作流在干净环境中重新构建；CI 结果与公开附件以 GitHub Release 为准。
