# ArcVellum v0.95.3

## Model Connections

- Added connection presets for DeepSeek, Zhipu AI, Alibaba Model Studio, Kimi, MiniMax, SiliconFlow, OpenAI, Anthropic, Gemini, OpenRouter, Groq, and other common services exposed by OpenCode.
- Added a guided custom OpenAI-compatible connection form. It stores the endpoint and model definitions locally so each isolated Agent Runner profile can be reconstructed after restart.
- API credentials remain in OpenCode's local credential storage and are not written into projects, Studio configuration, ordinary logs, or diagnostic exports.

## Reliable Model Selection

- Worker, advisor, and steward model selections now persist independently across application restarts.
- A selected model immediately replaces the stale startup catalog snapshot, so the interface no longer visually falls back to the bundled free DeepSeek model after a successful change.
- Idle OpenCode role services are recycled after a model or custom endpoint change. Active creative tasks keep their pinned model until completion, then use the new selection.

## Workflow Evidence Repair

- Rejected recovery attempts now require fresh Agent-authored task outputs. A timed-out sandbox cannot re-label stale review evidence as valid for a changed candidate.
- Progress labels now distinguish formal gate passes from independent creative deliverables.

## Verification

- Full Python suite: 386 tests passed.
- Vue client suite: 56 tests passed.
- Production frontend build and sidecar provenance checks passed before packaging.
