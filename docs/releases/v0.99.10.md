# ArcVellum v0.99.10

此版本集中修正长篇创作在资产初始化、事件规划、首轮篇幅与语言表现上的问题，并把相关修复开放给顶层 Agent 的受控工具接口。

## 资产与长篇规划

- 人物初始化现在会形成可供创作使用的背景因果、外形衣着、信念与意图、心理面具与边界、关系张力和个人语言方式。世界规则支持结构化条目，并按适用条件、边界与后果落盘。
- 资产生成改为逐人物与世界分批请求；每批最多一次结构返修，全部验证后再原子写入，避免一次响应过长造成残缺 JSON 或半套资产。
- 新增“只重排未写后缀”的顶层 Agent 权限。它以章级不可逆事件和用户认可方向重做未来场景，同步作品、计划和字数预算中的场数，但不触碰已提交正文，也不自动恢复创作。
- 滚动规划会读取全书已用事件及当前章事件预算；来源版本冲突后的恢复会准备新事务，不再反复尝试旧候选。

## 创作与语言

- 正文提示不再以全程朴素、匀速、短句白描为默认。它要求语言随入场、压力、转折与余波形成可听见的起伏，并允许自由间接引语、反讽、借代、通感、复沓、意象回返、长句推进、机锋与沉默按场景需要出现。
- 人物对白从词域、句形、礼貌边界、幽默与回避方式区分，不以滥用口头禅代替人物性格。
- 参考语料用于迁移句群呼吸、细节顺序、修辞发动、对白回弹与意象推进；仍禁止照抄样本表述。
- 生成阶段新增“证据之后停笔”，减少动作或意象已经传意后再用“不是……而是……”等抽象判断重复解释。禁词、反规避与中文标点继续由审查约束，没有移除或加强为新的文学门禁。
- 首轮创作在存在可恢复篇幅缺口时会在创作阶段继续完成，避免把本可一次完成的正文提前交给审查；字数仍不取代情节与语言判断。

## Agent 与设置

- 顶层 Agent 默认思考强度降低一级，创作 Agent 默认提高一级；两者均可在设置中独立调整并持久保存。
- 顶层 Agent 不再有固定工具调用次数上限。单次读取仍保留安全传输边界，超大结果会准确提示缩小查询范围，不再误称“工具额度耗尽”。
- 顶层 Agent 可受控追加章节，也可按明确事件方案重排未写场景；已提交创作、审查门禁和发布边界仍由正式状态机保护。

## 真实作品修复

- 《青春之旅》已补全六份人物档案以及世界规则；原长期运行保留为历史阻断，没有自动恢复。
- 《他与她》前 70 场合同、正文与提交凭据逐文件保持不变；未写部分重排为第 71—86 场，信、差额与代存物归属各只兑现一次，总目标仍为 300000 字符。原长期运行同样未自动恢复。

完整自动验证与仍需安装版复测的边界见 [发布验证记录](v0.99.10-verification.md)。提示词合同、静态回归和真实计划修复能证明机制已生效，但不等于所有题材的文学质量已经由盲评确认。
