# ArcVellum v0.99.16

本版围绕持续创作整理工作室体验：对话保留思路，资料随时可查，正文读到哪里就停在哪里，交付操作给出明确结果。

- **对话不中断。** 每段会话分别保留未发送草稿；中文输入法确认不再误发，发送失败不清空输入。回答过程中可以继续写下一句话，翻看旧消息不会被强行拉到底部，较早记录可以逐批展开。消息支持复制与重新编辑，TXT / Markdown 材料可直接放入输入框。
- **所有工具有统一入口。** Ctrl / ⌘ K 搜索功能与会话，输入“人物”“导出”“模型”等词即可找到对应位置。工作区返回后保留现场；对话框补齐焦点与键盘操作；旧路由保留会话与目标参数。
- **玻璃书房。** 调整导航、阅读与档案面板的透明层次，让共用星仪与纸张纹理透出来；优化对话、作品卡片、搜索浮层与反馈的排版。保留亮色、深色、高对比及减少动效模式，兼顾桌面与窄屏触控。
- **构思不会因为离开表单而丢失。** 作品库优先显示已有作品，支持检索；新建作品保留本机草稿，提供短篇、中篇、长篇规模预设，章数与场景数仍可自行指定。
- **阅读跟得上创作。** 正文搜索支持命中高亮与失败重试；修正快速切换章节、恢复阅读位置、更新正文与切换作品时的旧响应覆盖。输入搜索词时，方向键只移动光标。书签同步失败给出提示。
- **操作结果真正落地。** 导出使用带授权的文件请求，显示下载进度与错误；帮助中的诊断按钮现在会实际保存文件，“重新检查”会重新读取连接状态。取消或失败的回答不再显示成完成。

本版保留现有创作引擎、模型连接、文学审查与正式交付合同。草稿存储于当前设备；清除应用或浏览器数据会移除未发送草稿。v0.99.15 继续可下载作为回退版本。

Windows 提供安装程序、签名更新文件与校验和；macOS 为 Apple Silicon、Intel 未签名预览包。验收记录见 `docs/verification/studio-experience-20261031.md`。
