# ArcVellum v0.96.3

ArcVellum v0.96.3 是一版面向桌面可用性、Agent 执行边界和上下文成本可观测性的稳定
更新。它修复文风工坊和星仪的直接体验问题，也把模型实际看到什么、如何受控修订以及
越权改动如何恢复，收敛为可验证的工程合同。

## 用户可见修复

- 文风工坊的作者、作品和文风档案创建按钮不再因空标识静默失效。界面会根据名称生成
  可编辑的稳定标识，并在资料不足时明确提示尚缺什么。
- 桌面星仪的兼容渲染路径恢复聚焦、适配视野和章节簇切换的缓动动画；完整、减少动态和
  静止三种偏好仍然有效。
- OpenCode 流式连接超时会进入受控失败与恢复路径，不再以未处理线程错误结束。

## Agent Runtime 与预检

- 所有模型首轮资料由一个不可变 `ExecutionContextEnvelope` 表达，明确区分必须内联、
  按需读取、摘要引用和排除资料。
- 精确场景审查使用与候选正文、完整审查任务、Style Lint、字数、节奏、读者体验和文风
  证据绑定的紧凑上下文，不删除完整任务包。
- 确定性预检会在模型修复前恢复可由沙箱基线证明的越权改动：新建的越权文件删除，已有
  文件恢复；无法证明安全恢复的内容仍然 fail closed。
- 同一会话修复只接收当前错误、目标输出片段和受保护产物摘要，不再重新投喂整个项目。

## Bounded Canary

本版本加入合同驱动的 bounded canary 和隔离 A/B 工具，但生产默认继续使用
`shadow`，灰度开关默认关闭。

首个真实同模型样本中：

- shadow 与 bounded 均完成并通过首次 preflight；
- 首轮可见字符从 139668 降至 63967，下降 54.20%；
- mandatory 资料零缺失，资料层级零重叠，原正式项目 digest 未变化；
- bounded 的非缓存输入 Token 反而增加 9.23%，耗时增加 1.705 秒。

因此本版本只把该路径认定为 canary 候选，不宣称总体 Token 或时延已经改善。生产激活
仍需多场景样本、中位数/P95、文学质量不退化和 rollback 演练。
