# ArcVellum v0.99.14

本版重塑创作工作台，以 Agent 对话为视觉中心，统一人物档案、正文阅读、文风、质量和交付等界面的视觉层级。

- 使用纸白与雾绿的半透明界面、统一的图形语言和轻量动效。星仪成为持续保留的背景，进入星仪时收起工作台，返回后继续原有对话和草稿。
- 侧栏新增常驻“与角色交谈”入口；从人物档案进入时携带当前人物，关闭后返回档案。角色对话独立保存，主 Agent 的未发送内容保持可用。
- 整理档案页的字号、行距、分组和留白，去除旧深色底轨及嵌套表单暗色块。长文本自然换行，窄窗口通过工具栏展开资料索引或修改与版本面板。
- 统一新建资料、正文长卷、设置及其他工作区的显示。保留结构化编辑、专家源文本、候选晋升、回收站、版本检查与保存等原有操作。
- 改善星仪节点、标签、布局复用与增量投影，减少切换与更新时重复创建渲染对象的开销。
- 保留当前规划中的叙事设计信息，并加强已保存正文交付的恢复与修复预算核对。

Windows 提供安装程序、Tauri updater 签名及更新清单；macOS Apple Silicon 与 Intel 继续提供未签名预览包。本次发布不改变更新签名身份。验证范围及安装测试限制见同版本验证记录。
