# ArcVellum v0.97.0

ArcVellum v0.97.0 把 W6 编排工作流（AO-5 至 AO-8）的确定性契约层并入正式
生命周期，并修复文风工程链路中影响真实使用的编码与摘要问题。生产默认行为
不变：固定路线优先，自适应执行按分阶段计划逐步开放。

## 章节级编排契约（AO-5）

- Rolling Horizon 窗口：只对未来 2-4 个场景做深度推演，活动场景之后的窗口
  按章节库存确定性生成并校验。
- SceneRiskProfile：机器最低风险等级（compact/standard/deep），Planner
  只能建议升高；正式独立 AgentReview 永不豁免。
- 章节规划事实投影：事件库存、字数预算、节奏契约与承诺义务从正式项目文件
  确定性加载，并提供 measure-only shadow 评估。

## 资源锁与有限并发契约（AO-6）

- Execution Bundle 白名单编译器（chapter-planning、scene-analysis、
  scene-authoring、scene-quality、scene-state-extraction），单角色隔离。
- ContextCacheKey 精确失效、session lease 复用条件、OutputRepair 有界修复、
  ResourceGate 只读并行准入与写者串行。

## 全书重规划与无人值守契约（AO-7）

- Progress Fingerprint 只接受正式项目事实；ChapterCheckpoint 双指纹匹配恢复。
- 六类失败固定恢复阶梯、bounded replan 预算、无人值守 Campaign 暂停白名单
  与 fail-closed 边界。

## 前端产品化数据底座（AO-8）

- 创作策略只读投影 API 与 typed plan-event SSE；Agent 观测台安全投影。
- 前端页面入口暂缓开放，等界面设计完善后再启用。

## 稳定性修复

- 文风来源导入支持 UTF-8/GB18030/BIG5/UTF-16 自动或显式解码；NUL 填充自动
  剥离；损坏替换字符提供显式“移除并导入”（带数量提示）。
- 故事架构候选/独立审查的机器生命周期状态由 Worker 自动完成，自动推进不再
  卡在 `story architecture is incomplete: status`。
- 文风来源摘要统一为归一化文本摘要，导入、会话校验与投影一致，多段中文
  来源不再报 `style source content or digest is invalid`。

## 边界与默认行为

- 生产默认保持 `orchestration.enabled=false`、fixed 路线；W6 契约层不改变
  正式任务顺序与 Gate。
- Bundle 执行器、缓存存储、session pool、Campaign 长跑循环与交互式审批入口
  属后续执行器批次，未冒充完成。
- 真实项目长跑、干净虚拟机安装矩阵与真实稿件质量评估列为 owner acceptance。
