# ArcVellum v0.99.1

ArcVellum v0.99.1 是一次面向持续创作与长期维护的收敛发布：全自动创作不再被任务数、运行时长、估算费用或授权到期时间中断；星仪回归统一且辨识度明确的苔夜矿物视觉；代码边界重新通过架构棘轮。

## 不受时长与次数限制的全自动创作

- `full_auto` 仍需用户首次明确授权，但授权后不再设置任务数、运行小时、估算费用或到期时间上限；
- 旧项目里残留的 `max_tasks`、`max_runtime_hours`、`max_cost` 与 `expires_at` 会在读取时被规范化丢弃，不会悄悄恢复旧限额；
- 用户暂停、项目完成、Provider 配额、确定性 Gate 失败、连续修订失败、无进展与恢复耗尽仍会停止运行；
- 正文审查、晋升、Canon、人物状态、连续性和交付门禁没有放宽；本次移除的是 Autopilot 授权天花板，不是文学质量与运行安全边界。

## 统一的星仪视觉与叙事信号

- 移除 Iris、Obsidian、Bookcase、Modern 等备用色彩主题及不可达背景资源，保留统一的 Moss / Mineral 品牌视觉；
- 动效、纵深和渲染质量仍可按设备与可访问性需要调整；
- 新增“主脉 / 全部”信息密度：主脉模式优先展示章节、当前场景、主要人物与正在影响创作的证据；全部模式保留完整工程事实；
- 提升章节脉络、节点可读尺寸与关系线层级，长篇项目不会让所有档案资产同时争夺视觉注意力。

## 架构收敛

- v4 叙事投影拆分为创作图构建、版本摘要与响应载荷，保持完整图和稳定 revision 语义；
- FastAPI 叙事路由按 v2/v3/v4 注册，API 路径、默认参数、SSE 事件和错误状态不变；
- 星仪布局将节奏平滑、时间间距和章节成簇提取为独立纯算法模块，空间坐标公式保持不变；
- 工作台组件装配迁入中立组合目录，星仪不再直接导入其他 Feature 的具体页面；
- Architecture Audit 恢复通过：0 新依赖违规、0 循环、0 Studio 内部 Engine 实现导入。

## 兼容性

- 已有项目、任务包、正式正文和本地模型配置无需迁移；
- 旧主题偏好会自动归一到默认视觉，不弹出迁移提示；
- 用户的模型调用费用仍由所选 Provider 计费和限制，ArcVellum 不绕过 Provider 配额。

完整构建、安装包和测试证据见 [v0.99.1 发布验证记录](v0.99.1-verification.md)。
