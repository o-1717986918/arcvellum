# ArcVellum v0.95.1

## Task Receipt Reliability Hotfix

- Fixed a false blocker in formal longform generation: rerunning an unchanged deterministic CLI task no longer makes its completed platform-agent sidecar look stale solely because the task file was rewritten.
- Completion receipts now record a task-content digest. The system accepts a receipt only when it belongs to the same task content; a genuine reissued task still requires the Agent to read the new instructions and complete it again.
- Added regression coverage for repeated `word-budget` execution and for rejecting a completion receipt from a different task revision.

## Build And Repository Reliability

- Windows CI now provisions the pinned OpenCode executable, installation receipt, notice, and license before validating the Tauri shell, matching the production packaging contract.
- Added contributor, security, ownership, license, and changelog baselines. The `main` branch now requires the Python contract, Vue client, and desktop-shell checks; it also requires a review and resolved discussions while preserving an administrator emergency path.

## Verification

- Python unit suite: 348 tests passed locally.
- Version synchronization, Vue checks, frozen sidecar provenance, signed Tauri package, updater signature, installer, and update manifest run in the release workflow.
- The GitHub Release publishes the signed Windows x64 installer, updater signature, `latest.json`, and SHA256 checksums.
