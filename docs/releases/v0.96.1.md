# ArcVellum v0.96.1

ArcVellum v0.96.1 是面向桌面客户端的稳定性补丁，集中修复叙事星仪动效、文风语料导入和模型选择持久化。

## 修复内容

- 叙事星仪在摄像机静止时仍会刷新活动节点的轻微漂移，不再表现为完全静止。
- “完整呼吸”可以显式覆盖系统的减弱动态设置；同时保留“跟随系统”“克制动效”和“静止阅读”。
- 文风工坊支持从电脑选择多份 UTF-8 的 TXT 或 Markdown 文件，导入前显示队列、字符数和格式。
- 文件语料继续复用既有来源固化事务，保留权利声明、去重、指纹和工作台刷新机制。
- 模型角色选择改为选择后自动保存，并显示保存状态。
- 用户刚保存的模型目录不会再被较早发起的启动预热或启动流快照覆盖。
