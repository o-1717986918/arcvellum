# 默认文风参考语料目录

## 用途与分层

默认文风使用用户提供的二十五个完整文本单元。原文不删节、不改写，保存在 `training-sample.md`；新建项目时，同一份完整语料附入不可变挂载版本的 `style-profile.md`。`reference-index.json` 固定每段的原文跨度、哈希和技法标签。正式路线与 lean-v2 使用同一 Engine 选择器：场景匹配时注入一篇完整主参考、至多一篇互补辅参考；无可靠匹配时明确使用中性原则，不把二十五篇同时塞入单场 Prompt。

最近四场已完成创作的参考 ID 会降权；正式路线从 Prompt Manifest 读取，lean-v2 从完成的场景事务读取。同一场景返修沿用原选择，不会因为期间出现新场景而换样本。

模型面向的语料只包含文本和必要的机制索引，不夹带作者、版权、网址或长篇来源说明。来源声明仅保存在 `style_session.json` 的证据侧车中，不进入生成参考区。

## 二十五个单元

| 组别 | 单元 | 使用方式 |
|---|---|---|
| 象征、关系与克制现实 | R01—R07 | 正向机制库：象征揭示、关系观察、环境留白、动作承情、感官扩张、事实讽刺、对话喜剧 |
| 高强度宣告与神话尺度 | R08—R16 | 候选机制库：仅用于仪式性、公开宣言、群体牺牲或规模跃升的场景 |
| 类型氛围与空间定调 | R17—R25 | 正向参考库：用声光、气味、材质、空间尺度和可感危险建立雨夜离别、江湖、废土、朝堂、赛博、校园、恐怖、仙侠与宇宙等类型预期 |

R07 末句的引号未闭合属于用户原稿的保真内容。该单元的对话回弹可作机制参考，标点不作范本；生成结果仍必须通过现有中文标点审查。

## 生成与审查职责

- 生成阶段先根据人物欲望、场景功能和强度选一篇主参照，明确提取叙述距离、句群呼吸、细节进入顺序、修辞发动、对白回弹或意象推进中的至少两项，并贯穿初稿；必要时再取一篇辅助。模仿的是表达形态，正文仍写当前作品的人物与事件。
- 所有单元都作为正向参考使用：R01—R07 提供中低强度叙事机制，R08—R16 提供高强度语域，R17—R25 提供类型氛围和空间定调。每场以相合选段为主参照，不等于把二十五个单元都仿写一遍。
- 生成结果不得复制专名、标志句或连续措辞，也不得把相异声音拼成固定腔调。
- 默认“弹性叙事”不把白描、朴素或中等句长设为恒定底色；承压处允许扎根人物经验的自由间接引语、反讽、借代、通感、复沓、意象回返和长句推进。动作、意象、对白或物证已经传意时执行“证据之后停笔”，不追加解释性尾句。
- 违禁表达、机械对照和标点正确性仍由生成内复核、Style Lint 与 AgentReview 覆盖；逗号链、碎句和解释性心理等软审美风险的新默认等级为提醒，旧质量档案不静默迁移。
- 已挂载文风版本不可变；本批默认索引只随新版本用于新项目。旧版本没有索引时报告 `legacy-unindexed`，不会伪称已精准选择样本。
- 自建文风编译会从每份来源提取一段有句/段边界、最多 1200 字符的候选选段（最多十二份来源），写入 `style-profile.md` 并生成 `reference-index.json`。候选标签由确定性线索生成，可能需要人工修订；冻结文风版本前应检查每个选段的边界、功能标签与来源使用授权。没有可靠场景匹配时仍回退中性原则，不强配样本。索引跨度和哈希在版本构建时校验。
