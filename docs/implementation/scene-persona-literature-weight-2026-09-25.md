# 人格标签与文学风格比重微调

## 现场问题

顶层 Agent 发起的第二轮场景试跑中，主创为纪蔚、梁栖各写了五项内在性格、五项外显性格及七项额外语言标签，`[LITERATURE_STYLE]` 却各只有两项。多个标签描述本场动作、职业程序或当前情节，不是跨场景稳定的人格。环境初始化也写进了潮湿、天气和机器意象。该计划响应的 JSON 还存在多余括号，被解析器误截取后回退，因此这批候选没有送给一级 Agent。

## 本次改动

- 主创从性格／心理、外显气质、已有形象、稳定身份／种族、长期关系和适用的亚文化原型中，选少量能相互作用的人设标签；用户提供的大型词表作为选型参考，不整表注入每次任务。
- 角色初始化示例缩减非文学字段，把 `[LITERATURE_STYLE]` 展示为作家、流派、文学节奏三个维度；引导主创让这一节在风格表达上最醒目。固定挂载的 `ANTI_PLAIN`、`POLISHED`、`ANTI_SHORT_SENTENCES` 保留。
- 本场任务与动作仍交给后续局面和逐轮指令；具体环境意象仍交给环境 Agent 的后续场景输入。这是生成提示的调整，没有增加文学门禁。
- 主创正文与修订提示要求把一级推演重新编织为小说段落，运用引语、转述、自由间接引语、心理和空间变化，避免“台词—某某说／做—台词”反复排列。
- 计划响应只有一个完整 JSON 对象才可解析；无效计划允许一次重试。审读来源按实际提示剩余空间截取，避免资料溢出阻断正式路线。

## 验证边界

定向后端测试覆盖初始化引导、残缺 JSON 重试、来源长度及正文提示；架构审计通过。顶层 Agent 的第三轮试跑已实际送达角色与环境初始化，四项文学标签相对前一轮两项有所增加，但仍出现写实取向和本场意象进入初始化。此处只算结构改善，文学效果须以正式正文与审读结果判定。

## 追加根因与修正

第三轮电台试跑还暴露更上游的偏移：顶层 Agent 在创作方向、世界规则和全篇规划里写进了“克制短句”“不用心理与抽象比喻”“不为气氛加闲笔”。世界规则随后作为硬 canon 进入 SceneBrief，覆盖了角色和环境初始化的文学倾向。电台场景本身又以磁带、日志和封站交接为中心；主创逐轮引导集中在技术核对。这一稿应保留为偏技术化的对照样本，不能用它证明风格标签无效或已经奏效。

修正采用提示分工，而非新增审查门禁：顶层 Agent 将故事事实与文学表达愿望分开；世界资产只承载世界机制与因果，人物资产提炼稳定性格与关系；主创逐轮给演员关系压力和选择余地。角色初始消息继续只保留人格标签，第一次对戏输入另带该角色自己的经历、信念、隐痛、关系和语声资料，后续轮次沿用同一对话历史。主创与审查不再重复接收整份人物投影；审查所需的一级可见言行仍保留，隐念与导演计划不反复装入审查提示。旧事务缓存键保持稳定，以支持原节点续跑。

用户提供的标签词表按性格心理、外显气质、已确认身份形象、稳定关系及合适的亚文化原型检索。常用组合为三至五个相互作用的核心项；职业流程、场景任务与具体动作放在后续局面。`[LITERATURE_STYLE]` 继续承担主要文体方向。

开放奇幻试跑又证明，顶层 Agent 单靠一句“世界规则只写因果”仍会把章场数、视角、人物白名单和“不写设定说明段落”放入 world_facts 与 canon。规划提示原本还明确要求将某些结构限制逐条保存在 world_facts，形成了上游污染。已将顶层提示、长篇规划和世界资产提示统一为三层：世界事实与机制、篇章/视角/出场规划、可调整的文学表达。高自由度作品从少量可生长的机制和人物关系起步。

同一试跑的人物资产细化在不在场角色的 `intentions=[]` 上被结构校验阻断。空意向对离场/未知人物有意义；现允许心理、经历与关系列表保留空数组，仍检查字段类型和人物归属，不增加文学门禁。
