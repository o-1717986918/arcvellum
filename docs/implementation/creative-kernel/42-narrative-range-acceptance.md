# 宏观叙述与完整取材展示：本轮调整结果

## 为什么原稿容易写成克制的现实主义场面

原作首场实际调用了五类取材器：7 次委托，17 条候选。少调某个类别并非主要原因。主创把世界信息委托成“人物此刻所知的一点信息”，把环境、人物和场面集中到物件、触觉与局部动作，最终以对戏组织正文。

上游也存在同向引导：长篇规划要求每段都有参与人物与冲突；落盘的节奏统一压低概述；人物补全要求隐藏创伤；章级文学任务没有形成对应资产。文风参考选择遗漏作品题材，“关系”让现实主义关系参考 R02 与喜剧参考 R07 同分，旧排序取了 R02。资料摘录与取材上下文再裁剪，削弱了世界机制的完整性。

因此，本轮同时调整规划、主创选择、领域取材、资料传递与参考选择。单改“多写世界观”不足以解除这些同向引导。

## 已落地的改动

| 环节 | 当前实现 |
| --- | --- |
| 长篇规划 | 明确章级文学任务、叙述者声音、世界呈现方式和本段叙述策略；允许参与人物为空、冲突为空；概述与细写由文学任务选择。 |
| 主创 | 先判断章节在全书中的阅读作用，再选择世界介绍、过程概述、人物现场或其组合；按文学用途委托取材。 |
| 四类非角色取材 | 环境可写地方、景观和季节；人物可写生活习性与群体差异；叙述可写世界、制度、历史与长过程；场面可组织群像和并行关系。角色卡继续是角色唯一人格初始化。 |
| 取材分派 | 使用新版环境初始化的交易直接执行主创委托；已有旧规划缓存继续使用，旧版交易恢复原合同。独立规划不再为新委托重新编排场景。 |
| 素材容量 | 文学素材容量由 600/700 字增到 12000 字，来源札记由 240 字增到 4000 字；上下文预算继续显式校验。 |
| 来源资料 | 取材收到本段完整 Canon 约束；取消描写器对来源的第二次 5000 字裁剪；世界规则获得更充分的摘录空间，预算裁剪附节选标记。 |
| 文风参考 | 加入作品题材与审美、叙述策略及章节任务；记录同分参考，允许主创选取适合的表达技术。相同原作资料重放时主参考从 R02 改为 R07。 |
| 冻结与恢复 | 固定模板渲染使用交易快照；已经收到的取材先保存，再校验，恢复可以重处理原文。混合来源状态按提案保存完整说明；缺少来源元数据时明确记录缺失，并按提案处理。 |
| 前端 | “推演观察 → 全部取材素材”展示全部已保存候选、委托、来源、取舍和长文本；失败交付保留原始内容。创作现场也可查看素材。 |

本轮涉及 31 个提示词资产，包含 v1 和 v2。可编辑模板在“设置 → 提示词工作台”查看、修改；固定交付协议供查看。角色卡结构沿用。v2 的全局启用状态沿用当前配置。

## 真实文学证据及其范围

在独立作品、独立数据目录，使用注册的当前模型与真实世界规则生成了宏观开场。首份候选以“先说路”进入，概述道路、巡林手艺、招牌糖霜、待客权与付款习惯，随后收束到咖啡馆门前。主创实际委托环境、事件叙述、场面取材，共 5 次委托、16 条素材；没有把开场改写成具名人物对话。

独立模型审读认可了讲述者声音和宏观介绍，但候选带着验收作品最初复制的原作已提交历史说明，审读据此升级。删除测试作品的历史状态后重放旧候选仍携带这项说明，故保留 blocked 结果。正式作品没有被替换。

修正资料传递与分派后，同一独立验收交易重新完成创作：当前稿 1422 个中文内容字，5 项主创委托，保存素材投影 21 条。已通过确定性检查与独立模型审读，并完成独立作品内的正文、SceneDelta、连续性、提交记录写回；写回正文与模型候选逐字一致。交易为 `scene-tx-033fd6306e3e4e2bb8fc54b286798441`，状态 `committed`。恢复过程使用已保存的素材并保留之前的失败；21 条指这笔交易保存的素材，不等于 21 次新调用。

本 Agent 仍认为当前稿对石阶、招牌的连续细写偏重；“得留三分”是新增制作惯例，原资料只说不可无限刮取，“米拉抵押过”也把资料中的可能性写成既成事件。模型审读将它们认为成立，这些分歧保留在报告中。后续需检验主创的设定取舍及详略判断，不能把本次 pass 当作文学风格完全达标。

这证明当前链路能表达宏观叙述，并不证明所有题材都已具有充分文风。首份候选仍有密集短句、重复拟人和部分规则措辞不够精确的地方；浪漫、奇异与喜剧的强度还需逐篇阅读判断。本 Agent 的这一判断与模型对节奏的肯定一并保留。

这也不是严格同条件正文 A/B：新验收作品的文风修订与原作品不同。参考选择的同资料重放、界面的真实素材回放、实际正文生成三类证据分别解释。
