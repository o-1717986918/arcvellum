# 当前思考降档与素材利用核对

2026-10-11，作者要求降低实际思考强度，并核查主创是否过度咨询取材器、过量挂载而少量采用。当前共享配置的创作偏好从 medium 调为 low，项目总控从 high 调为 low；既有技术整理角色仍为 off。通过 application.config 的既有公开偏好保存接口落盘，模型选择保持 deepseek/deepseek-v4-flash。本轮没有恢复真实付费测试，也没有新增费用、调用或时间预算。

主模块为 Studio Pi Worker adapter。内置 Pi 0.84.1 的 DeepSeek V4 目录把 low 标为不支持，原 safeThinkingLevel 和 SDK 二次能力校验会把 low 降为 off。当前适配器对已知 V4 Flash/Pro 和官方别名、且使用 DeepSeek thinking 格式的模型作不可变能力补充，向模型副本提供 minimal/low -> low 映射。会话、正式 Worker 和 Project Agent 均使用该模型副本，原模型目录、模型 ID、端点、凭据及价格字段不变；旧 DeepSeek 和其他稀疏目录仍按其声明能力处理。

实际 Pi SDK 离线请求序列化核对了 low -> thinking enabled + reasoning_effort low，以及 off -> thinking disabled。捕获 onPayload 后在网络发送前停止，模拟 fetch 的调用数为零。这证明参数序列化，不证明真实服务响应、文学质量或节省金额。已重建当前仓库的 workers/pi-worker/dist；改动从后续读取本配置的新调用生效，已保存的历史运行记录保持原强度。
