# 创作内核：文学判断依据

本项目把主创意图表述为“希望读者怎样经历这一场”，并记录可供读者推想的线索与刻意保留的未知。意图是主创可修订的工作判断，不是必须填满的审美分类，也不是 Canon。

- 福斯特把人物、情节、形式和节奏分开讨论。复杂人物需要稳定性，也有可信的意外。[《小说面面观》](https://www.gutenberg.org/files/70492/70492-h/70492-h.htm)
- 伍尔夫讨论普通一天中意识接收的印象，反对以惯常情节格子限定小说材料。王安忆谈到情节、细节和人物，也以市井人物的声音与关系说明自己的兴趣。我据此把日常细节、停留、趣味和人物展示视为可选择的场景价值，而不是把这项推论直接归作她的原话。[《现代小说》](https://www.gutenberg.org/cache/epub/64457/pg64457-images.html)、[王安忆访谈](https://www.chinawriter.com.cn/news/2013/2013-04-01/158415.html)
- 巴特讨论延缓、加速及气氛的叙事功能；伊瑟讨论读者填补文本空白。留白须有可回看的线索，误导须可追溯，不能把漏写当成设计。[巴特](https://www.davidbardschwarz.com/pdf/barthes.pdf)、[伊瑟](https://teoriaciek.wordpress.com/wp-content/uploads/2010/10/iser_the-reading-process.pdf)

角色 agent 的人格化指引是文学能力的必要组成：稳定身份、内在反差和语言气质应在初始化保留；压力、关系与局部感知放在逐轮任务中，使人物既有辨识度，也能变化。不能把人格化提示本身列为缺陷。动态人格研究支持区分稳定身份与历史依赖的心理变化；Dramatron 的作者反馈提醒，分层上下文仍可能欠缺人物动机和潜台词。新增描写器是否改善成稿需要盲评。[动态人格研究](https://aclanthology.org/2026.acl-long.1336/)、[Dramatron](https://arxiv.org/abs/2209.14958/)

验收不以情节推进或词数为唯一标准。人评观察人物辨识、日常细节取舍、留白线索、趣味、误导公平性、节奏、视角和跨场景连续性；事实和权限由程序检验。自动文学评审只作辅助。[LitBench](https://aclanthology.org/2026.eacl-long.362/)
