# 创作链路验收：本批有作品特色，流程仍未收敛

本批从 2026-10-07 执行至 10-08，使用配置中的 deepseek/deepseek-v4-flash。四类案例均已启动，冲突第一场完成正式审读、Gate 和写回；其第二场，以及空间、设定、计量日常的后续推进被网络终止或超时阻断。日常未开启计量的第一场达到三次文学返修限额。四组连续两场、同条件独立复测和完整编辑开启链路仍待完成。

费用台账记录 176 次 Gateway 调用，402 条去重后的 Provider 用量更新，已报告目录估算约 $1.038147。两条调用缺少用量或费用；实际服务商账单未核验。Gateway 一次调用可能包含多次模型请求。当前最大的已报告费用来自后置整理，约 $0.546974；文学返修阶段约 $0.243424，其中也可能包含主创补查和新的委托。本 Agent 的开发与阅读费用未计入。

以下细读由本 Agent 产生，阅读时已知版本来源；实际审读信由配置模型产生。报告中的 A/B 页面可供用户隐藏来源、交换顺序后另行评审。本批没有完成独立盲评或人类文学效果验收。

## 1. 日常：物件确实承担了感情，连接处也确实有漏洞

读第一稿与第七稿，“那道勒法她认得”“三年零两个月，我记着呢”“汤要凉了”分别把熟悉、报账和挽留安在物与口头习惯里。陶婶的分量、火候和手上的动作，与许钉的工时、欠账、工具构成两副声音。读者能先于人物听见那句“留下”。以“钳口”和汤面收束的方向有余韵，比解释她舍不得更有文学强度。

主要问题是物件交接。第七稿开头写“他把搪瓷碗翻过来，先给她看，再搁上台面”，接着沿碗底锔子描写；读者可能理解为倒扣放下，后面汤进碗前缺少明确翻正的动作。同稿先写“锅盖在灶上跳一声，又一声”，紧接着又说“锅盖还握在手里”，状态确实不相容。工具包在早期稿里也曾移位，第七稿已补上“弯腰把工具包拎起来挎上肩”。不同取材者给出的完整场景各有自己的物件安排，主创使用其中几块时没有始终合成一条能跟随的行动线。

角色素材有长处，也有副作用：许钉的原始回应自行加入陶婶“谁跟你算这个”等台词。台词和互动很有活力，却使主创拿到的是另一版完整小场景，连同双方回应和摆放方案。五类不宜以素材篇幅相加来理解价值；主创需要选择同一套动作关系。

审读多次说结构成立、建议小修，但早期关注点从句法、视点转到工具包，后期才发现碗与锅盖问题。返修有实际收益，尚无证据证明十轮返修都值得。把完整审读信传入修订上下文，能保留“这一处为什么成立”和具体改法；它不能代替对返修收益的进一步真实复测。

## 2. 冲突：人物的理由进入了动作，结尾的计时需要再辨认

已提交第六稿中，顾砚用“哪条船，谁的名字，押的哪一笔”面对季桑的“七个。柳湾高墩”。两人分别从账目与生命数量开口，冲突来自不同的算理。顾砚把指节从“顺水”挪到日期栏、季桑以拇指拖出红线，改变通过动作发生。“他的，我认”有力度，主创让它成为开柜前的转折，而没有把救人后的画面提前用完。

主创确实舍弃了不合适的素材：事件候选里页号、编号与“两把钥匙”未入本场；一个空间素材把季桑写成女性、钥匙挂到柜边，主创记录了修正理由；角色候选“上船。坐稳。别回头”留到开柜之后。这些可在素材原稿、候选 ID 和主创取舍表逐项核对。

已提交并不等于所有文学疑问消失。水位从离红漆十一格到一格，短短对话中上涨很快；若它作为紧迫感的计时器，应与洪水速度及下一场衔接相称。结尾“绳在窗外绷着，两声蹭响中间已经没有空”有可感的压力，但一格的时间尺度仍值得用户判断。第二场尚未生成，无法检查这一悬念是否兑现。

## 3. 空间与设定：已有触觉组织，尚缺连续完成的证据

空间初稿以手辨别绳的“卡”和“死”，用侧幕、景片、脚步与沙沙声带读者绕后台。手、听觉和遮挡承担取景，素材领域特色清楚。长段“卡是有回话的”反复展开同一对比，既可能形成工人的身体知识，也可能把开场的紧迫拖成讲解。主创从有限视点写到白禾“想咬舌头”，有视点游移；备用绳的连接动作还没有完成。本批只产生初稿，技术 Gate 后的修订被网络中断，尚未有独立文学审读。

设定揭示《盐仓记事》只完成一位角色的真实素材调用，第二位角色超时。没有正文，不能评价设定如何进入叙事或悬念的延续。案例与原交易均保留。

## 4. 去 AI 味：同稿能比较，但目前不是强收益证据

固定日常第三稿进行实际编辑，原编辑提出五处建议。最初整理出的 rule_id 是“规则8（已有材料的表达）”等标题，而接受器需要既有编号，五处都被拒绝。改为按明确编号整理，并恢复来源中的原引号后，用保存的同一编辑原稿复测；最终两处采纳、三处拒绝，未重新生成编辑意见。

一处将“她绕到桌子南面站住”改为“她在桌子南面站住”，减少不必要的移动，表达更准确。另一处把“厅里剩她一个，两只手按在那只碗上……”改为“她两只手按在台面上，按住那道月牙形的白……”，修补物件关系，同时改变了动作；这一处不应计为单纯去 AI 味收益。其余包括把“她”写成“他”、依赖前一处已修改文字、碰到 SceneDelta 原文证据的建议均保留原文。

原稿有生活质地，未表现为整篇模板腔。此轮最需要防止的是编辑把故事动作当成局部措辞改掉。编辑模板已把动作、位置和缺失事件作为给主创的札记，将直接替换聚焦到表达。新模板的文学收益还未进行真实模型复测；去 AI 味继续是实验可选功能，完整开启—审读—写回对照尚未完成。

## 5. 计量：对白向目标靠近，其余三项反向移动

画像来自日常、冲突的两篇真实模型初稿，来源声明保存在 model-baseline-source.json；这是小样，不是作家语料，也不代表稳定作者文风。两组日常使用相同档案、初始人格、作者意图和模型，但提示词及整理代码在测试中有所修订。以下为描述性对照，不能把差异都归因于挂载。

目标句长为 11.7317–15.8723 汉字，段长为 24.685445–33.397955，对白比为 0.384795–0.520605，标点密度为 158.53656–214.49064。未挂载初稿实测分别为 13.802、29.6596、0.1399、196.5567；挂载初稿为 9.5417、18.6939、0.3035、258.7336。对白更接近目标，句段更碎、停顿更密。挂载第二稿为 10.6739、20.4583、0.279、245.4175，仍四项超界。

挂载稿有“数到三她才明白自己在数”“桌子咬住了纸”等有质地的句子；新增广播时点让欲留与赶车的压力相遇。审读发现了两只带缺口白碗混淆、盛汤时“碗底朝着他”的动作问题。数字接近度与文学成立是两项判断，不能以其一替代另一。25 类参数可测的项目、是否启用及距离列在完整测量中，依存句法为未测量。本批仍需同一提示词版本、真实作者画像和独立生成的严格开关对照。

## 6. 独立角色：名字填清后身份稳定，替人回应仍待修正

陶婶与许钉各接受四轮刺激，又各以明确的新来维修工“小陆”上下文重复四轮。两组共 16 次实际调用。已有主创取材文件的内容摘要均未变化；独立对话的事实与历史另行保存，技术回归也覆盖角色知识与上下文隔离。

去掉说话人标签，按词域仍能辨别人物。陶婶说“汤在灶上呢，我惦记它别沸过了头”，以铁盒底锈、屉布和下米分量处理新关系；许钉说“换平了，我才走得动”，用垫片、螺丝和十七件待修零碎说欠情。缓和刺激后他开始找具体修理步骤，延后一天后算能多交几件活，反应随处境变化。

无身份上下文时，许钉把用户当食堂主人；明确“小陆”后识别为初见维修工。但他仍自行写出小陆“走哪儿去？”“下面”等回答，且重复卡内“去挣钱”“不是躲”等例句。陶婶有时从第一人称转成第三人称动作，角色卡的倾向也可能变成随处展示的标签。委托和角色卡填写任务已增加处境触发及当前回应的正向引导，原卡模板结构保留；新任务的完整真实复测仍待执行。

知识挂载存在一个内容判断缺陷：旧委托将 SceneBrief 的后续目标挂到角色可知区，容易使角色预先照计划表演。新委托模板已引导把见闻与创作规划分开。来源路径和冻结摘要可追溯；程序能验证选择与分区传递，不能自行证明某条作者规划就是角色已经知道的事实。因此，知识传递技术回归通过，文学上的知识判断验收仍未完成。

## 7. 修复、验证和仍需继续的工作

已修复：主创与可选编辑共用交易冻结文风，保留补充／替换／仅观测语义；自然委托的引号、列表与知识区别名整理；有界、完整素材的原文打包与长文后置整理；同源失败缓存重验；交接目标先验证并重提取；原审读信与被审正文绑定；同提示真实重试的消费身份；工具调用双重计数；部分回答遇网络错误时的假完成消息；角色页面换作品后的迟到回复。新增档案读取回执使以后能核对主创具体读过的条目、行段及版本。旧工具事件只有名称，旧测试的条目级自由阅读证据缺失，不能补造。

主创提示词的修订围绕独立邀请、素材行动连贯、完整审读问题与中文正文排版分别进行；角色卡结构保持。提示词差异另存 prompt-diff.patch，交易保留精确文本及摘要。早期运行仅记录结束时的代码提交，不能据此认定运行起点的完整代码状态；新入口已增加开场提交、工作区差异摘要和批次限额。并可在已有提示词工作台查看、修改和评审。旧交易继续用已冻结模板，因此旧稿不会被当前模板追溯改写。

回归：运行时 63 项、应用／角色／验收 18 项通过；前端 272 项通过并完成构建；Worker 124 项通过并完成构建；架构检查无新债务，提示词注册表通过。前端首轮全套出现一次旧路由导入超时，独立复测及全套重跑通过；没有改动该路由。真实角色页面已检查桌面、手机无横向溢出与主要区域重叠，加载、冻结行段、恢复实际对话均通过，未追加模型请求。

提示词页面还复现了加载时先输入搜索、目录返回后匹配叶子未展开的问题，已修复并补回归。工作台实际展示了新的 v2 候选取舍模板，保存临时作品版本、组装预览和恢复默认均通过，旧主创提示词仍可读取；该试填只写入隔离作品的版本历史。

测试过程自身也有两项失误：在 Worker 构建窗口启动了一次角色调用，导致入口文件暂不可用；恢复进程曾同时写同一隔离变体，导致一次版本冲突。已增加变体进程锁，后续 Worker 构建在真实调用结束后进行。两项与 Provider 网络终止分开记录，原测试数据保留。

下一批仍需完成：四类第二场及设定第一场；最终模板原案例、另一案例和独立生成复测；严格控制提示词版本的计量对照；实验编辑完整成稿链路；去标签声线的独立评审；顶层 Agent 从用户输入到人格初始化的完整 UI 编排。本批人格经顶层人格模板真实生成并保存，但未验证顶层 Agent 整段工具操作，因此用户方向—人格—场景的全前端闭环尚未完成。

本批未达到“两轮主要问题修正后无文学和流程阻碍”的收束标准。已有档案初始化和场景审读／写回机制均保留；只在隔离验收实例启用 v2，没有更新用户作品与旧交易。网络失败后停止新增付费测试与重复尝试，后续可从报告关联的原交易继续。

## 评审方法的依据

展示次序、篇幅和自我偏好会影响模型成对评审，因此保留正文证据、评审来源及分歧，并提供交换顺序的用户阅读入口。[模型评审偏差研究](https://arxiv.org/abs/2306.05685)

自然程度、风格强度和意义保留分开判断。[文本风格迁移评估研究](https://aclanthology.org/N19-1049/) 本批没有把计量距离或检测器得分当成文学质量结论。
