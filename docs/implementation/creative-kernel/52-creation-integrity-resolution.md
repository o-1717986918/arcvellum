# Creation integrity resolution

Engine owns `scene-consistency/v1`, author fact/Canon classification, cumulative draft dispositions and current-candidate review evidence. Studio consumes public exports, archives explicit author records, binds checks to body hashes and invokes only the registered original author/reviewer for correction. New transactions enable the contract by configuration; old frozen transactions keep their snapshots.

Review findings must quote the current body, locate the problematic fragment in their own evidence and revalidate historical issue IDs. Author-selected paragraph references are resolved only against the current body SHA and existing block IDs. Review arithmetic alerts cover only narrow adjacent last-year/three-or-more-year narration; they require issue or uncertainty review, not automatic prose rewriting. Speech, separate events and explicit temporal jumps are excluded. Semantic consistency remains an independent review responsibility.

Each revision accounts for every previous uncommitted proposal by retaining, replacing or explicitly withdrawing it. A durable new/changed fact points to an actual current Delta proposal. Canon proposals remain candidates; existing approval/apply gates and the atomic writer remain authoritative.

Every current material receives an author decision. Adopted material has exact source evidence and a current-body landing or explained indirect use. Repeat demand first reviews all related existing candidates. Deferral and rejection remain valid author choices.

The default corpus adds six verified excerpts from Lu Xun, Xu Dishan and Yu Dafu, preserving the original eight classical excerpts and twenty-five user references. New mounts receive 39 reference units; old immutable mounts are retained. New headings support non-chapter locators without fabricating chapter numbers.

Validation includes cumulative-Delta loss, stale review retraction, incorrect current hashes, time-alert exclusions, all-related-material checking, malformed author metadata and local delivery without formatter calls. Isolated Discovery tests preserve Qwen failures and explicitly select GLM 5.3 with native Pi SDK thinking enabled. No API-key store, provider abstraction, direct HTTP model client or hidden fallback was added.
