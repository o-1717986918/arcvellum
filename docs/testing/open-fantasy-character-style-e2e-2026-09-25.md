# 开放奇幻角色文风端到端测试

## 要验证什么

电台交接样本的技术化语言同时受题材和上游硬化的叙述禁令影响，不能单凭它评价角色/环境 Agent。新测试选用随季风迁徙的群岛和“亲历故事使岛间道路显现”的开放奇幻前提，观察人格标签、角色自身背景视角、逐轮关系推进、环境取景和主创组织正文的实际效果。全程从顶层 Agent 会话启动，目标为一个正式单元；只有完成审查与晋升才计正式成稿。

该项目正式晋升 `scene_0001.md`：目标 `autopilot-91f87350cfa444a9`、事务 `scene-tx-5d02077bdf1f4b87acc4e4d63b96a508`，主创初稿和一轮修订后审查 `pass`，以 `goal-scope-complete` 暂停，估计费用约 0.055 美元。顶层自拟方向缩至世界前提与短幅宏观意图，主创自行创造阿绡、敖栖、沈无咎、槐序；第一轮由阿绡先表演，下一人接住其实际发言，前一版的因果顺序错误没有复现。谎兽现身后主创又请求三轮角色续演。正式正文的事件顺序可以理解，但文本仍停在暖房锁、地图留白、花道方位、桥板错位和“三个晚上”等手续细节上，人物心理与关系只露出一角；独立审查将不同职业口吻视作声音区分，文学质量判断不充分。

根因再往下追一层：本轮实际初始化标签有 `ANTI_PLAIN`、`POLISHED`、`ANTI_SHORT_SENTENCES`，但首轮角色输入又附上完整 `speech_style`，阿绡明确写“干活时短句碎话”，沈无咎写“短句，先记录再发问”，两人的高频词分别围着钥匙和坐标；这等于以细化资产压过抽象风格。完整初始化见 `docs/testing/moonlit-lie-beasts-free-initialization-2026-09-25.md`。旧角色持久对话还先让演员对无场景初始化独自作答，并把这一答复带入后续历史：阿绡的空场思考直称“开场白”，敖栖说自己被“加载”出来，沈无咎凭空招呼对方“茶还是水”。这不是正文直接引用，却造成首轮视角污染和一次多余模型调用。主创追加的三轮 cue 又变成“过桥、绕道还是留守”的行动菜单，持续把戏引回空间调度。

修订方向以生成阶段为主：角色初始化升到无竞争系统层，首条模型回复就接真实场景；每轮重建的持久历史只包含真实场景言行，不再保存空场答复。人物首轮仍得到背景、欲望、秘密和关系，去掉重复塞入的具体 `speech_style` 清单；声音资产生成提示将日常、争吵与旧事的口头来历置于职业词之前。主创的轮间 cue 强调感受到的关系压力与新信息，具体情节必要时仍可明确动作；正文提示把关系发生的瞬间前置，再随人物知觉展开环境。没有增加文学硬门禁，也没有修改违禁词或标点硬审查。

这轮还显示一个费用与审美问题：主创为了让双名请柬的魔法效果成立，添加了原演员未表演过的接取或摊开动作，现有一级行为归属核对连续要求修订，直到改回有来源的举止。归属要求来自用户此前“人物发言与行为由一级角色 Agent 生成”，所以本轮未放松此门禁；更合适的上游做法是让主创在情节需要时请求角色续演。顶层 Agent 最终报告把“项目级人物初始化标签尚未配置”和“本场角色初始化已执行”混为一谈；场景持久记录明确证明后者已执行，顶层总结不能当作一级机制是否运行的唯一证据。
