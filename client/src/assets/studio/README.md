# Shared vellum orbital material

`vellum-orbits.webp` is one reusable transparent artwork for the application shell, welcome area, workspace headers, and character conversation. It is not generated per work and contains no product text, icons or controls.

- Created with the built-in `image_gen` tool on 2026-10-17.
- Original: 1774 × 887 RGBA PNG. Converted losslessly to RGBA WebP with Pillow; 578,334 bytes. No creative post-editing.
- The actual Orrery remains the background renderer. This asset is a peripheral material accent.
- Motion is CSS-only, and is disabled by reduced-motion/high-contrast preferences.

## Generation prompt

Create one reusable transparent-background art asset for ArcVellum, a sophisticated literary writing application. Asset only, no interface, no frame, no text, no logos, no book-specific scenery. A delicate abstract sculpture of three translucent vellum ribbons curling into incomplete orbital arcs, with a few hairline muted brass filaments following their curves. Their thin paper edges catch soft daylight; the translucent layers have subtle mineral-green / cool pearl / restrained grey-violet tints. Wide horizontal composition with the material mainly in the RIGHT half and upper-right, airy open empty space toward the left, irregular organically fading silhouette. High-key gentle daylight, exquisite paper microtexture, premium editorial art direction, finely layered depth, no dark void, no saturated purple, no blue neon, no glowing space planets. The work will be reused as a small corner ornament and a very subtle atmospheric layer behind a live narrative graph across all books. True transparent background including all empty regions; no drawn checkerboard, no opaque rectangle, no ground plane. Large enough for clean desktop rendering. Prioritize beautiful restrained material and flowing curves over bulky 3D objects.
