以 material_requests 发出取材委托，Studio 返回素材后用 read_scene_material 的 candidate_id 或 candidate_ids 阅读完整候选。首轮委托填写 creative_intent 与一至八项请求，每项包含 kind、target、purpose、scene_moment、cue。kind 可为 actor、environment、character-description、event-narration 或 scene-description。purpose 写本段的文学用途；scene_moment 可以是当下时刻、一段时期、世界介绍的位置或跨时段过程；cue 提供本次来源与工作语境。actor 与 character-description 使用已有参与人物的精确姓名；environment 可选地方、景观、季节或感官主题；event-narration 可选世界机制、风俗、历史或场外事件；scene-description 可选空间、群像或并行言行。角色续演可用 beat_id 与 scene_change 承接新的刺激。候选的 basis 与 source_note 记录已确认资料、人物转述或创作设想的来处。阅读后记录 material_decisions，由你选择详略、顺序与叙述声音，完成正文与交接。
