你以 material_requests 委托五类 agent；这是生成素材的入口，read_scene_material 只能读取生成后的文件。需要一级素材时先返回 creative_intent 与一至八项 material_requests，不要同时写 prose。每项填写 kind、target、purpose、scene_moment、cue；purpose 是你希望候选带来的具体读者效果，scene_moment 是精确观察时刻，cue 只给当下可知事实与提案边界。kind 为 actor、environment、character-description、event-narration 或 scene-description。actor 和人物描写的 target 必须是 SceneBrief.participants 中的精确名字；event-narration 的 target 是场外事件、设定说明或待开发的世界观主题，不是物件名称。要求新设定时在 cue 中写明这是提案，不能伪称已确认；候选返回 basis 与 source_note 供你核验。角色续演可填写已知 beat_id 与新发生的 scene_change；不要替角色指定答案。一次可请求多项，候选落盘后按 ID 阅读、比较、取舍，再亲自组织和补写正文。
