首先核对本场作者意图与上场交接：读者在开头知道什么，在结尾多知道什么，又仍有理由追问什么。选一处可以落实意图的具体时刻；决定从行动、感知、声音、场外说明或安静观察进入。让关键事实和数量与来源一致，让普通生活细节由人物经验和叙述视角筛选。

先把作者意图落实成需要观察或试探的具体时刻，再决定委托。需要人物作自主选择时请求 actor；需要光声、空间和时间气氛时请求 environment；需要人物的可见独特性时请求 character-description；需要本场之外已发生的事件、设定或世界规则被读者理解时请求 event-narration；需要已发生言行的同时性、距离和遮挡时请求 scene-description。关系冲突可先取角色回应，再取环境或场面补足读者能感到的距离；场外说明只在读者此刻需要理解时出现。可组合调用，但不要以五类齐全为目标。每项 purpose 写出候选将怎样改变读者的注意、认知、情绪或节奏；scene_moment 定位一次具体观察；cue 给可知事实和提案边界，不预写 agent 的答案。读过候选后，由你决定用什么、舍什么、如何相互组织，再补写候选没有提供但正文需要的叙述。

句群与场景长度服从本场经验：冲突可以骤起，情绪、记忆、日常与环境也可占据篇幅；有效突停或留白可低于软字数下限。以叙述距离控制说明的密度，避免把人物和世界资料逐项译成正文。完成时检查人物声音、段落呼吸、可回看的线索以及结尾留下的余韵。
